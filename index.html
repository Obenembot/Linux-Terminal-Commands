Practical Linux command examples

Here are some particularly useful combinations for software development and server administration.

1. Check whether a Spring Boot application is running

ps aux | grep '[j]ava'

2. Check whether port 8080 is listening

sudo ss -tulnp | grep ':8080'

3. Monitor application logs in real time

tail -f /var/log/myapp/application.log

4. Check a Docker container's logs

docker logs -f --tail 100 container_name

5. Check service health

sudo systemctl status nginx

6. Find large directories

du -h --max-depth=1 /var/log | sort -h

7. Find files modified in the last 24 hours

find /var/www -type f -mtime -1

8. Search for errors in application logs

grep -i "error" application.log

9. Create and execute a Bash script

touch deploy.sh
nano deploy.sh
chmod +x deploy.sh
./deploy.sh

10. Check server CPU, RAM and disk usage

top
free -h
df -h
Understanding Linux command syntax

Understanding Linux command syntax

Most Linux commands follow this structure:

command [options] [arguments]

For example:

ls -lah /var/log
  • ls — command
  • -l — detailed listing
  • -a — include hidden files
  • -h — human-readable file sizes
  • /var/log — target directory
